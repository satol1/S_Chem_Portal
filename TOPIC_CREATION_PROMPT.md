# Входной промпт создания новой учебной темы (S_Chem_Portal)

> Единственный регламент производства тем — [`docs/topic-standard/00-PIPELINE.md`](docs/topic-standard/00-PIPELINE.md) и модули стандарта. Данный файл — **шаблон запуска**: заполните заполнители и отдайте координатору (Qwen Code). Нормы в промпт не копировать — агенты читают их с диска.

## Шаблон задания (заполнить и отправить)

```
Создай новую учебную тему по конвейеру docs/topic-standard/00-PIPELINE.md.

Тема: <название, напр. «Кремний и его соединения»>
Семейство: <ХЭ-NN (химия элементов) | ОХ-NN (общая химия)>
Подгруппа/элементы/раздел: <напр. «IV-A, неметаллы» или «Раздел 7 • Кинетика и равновесие»>
Особенности (опционально): <акценты, отклонения, пожелания к схемам/инфографике>

Порядок работы:
1. Прочитай 00-PIPELINE.md (§2 чек-лист + §3 реестр эталонов), профиль семейства
   в docs/topic-standard/topic-types/ и _TEMPLATE.md паспорта. Другие модули
   стандарта читай выборочно по «карте чтения» из 00-PIPELINE — не целиком.
2. Шаг 0 — паспорт темы в docs/topic-passports/<slug>.md.
   Для ОХ-темы: каркас уже существует — он ценен только как разметка разделов
   (navItems, id секций, шапка, регистрация); содержимое каркаса не норма,
   тема наполняется полностью поверх этой разметки (general-topic.md).
3. Шаг 1 — черновик теории; запусти АГЕНТА НАУЧНОЙ ВЕРИФИКАЦИИ самостоятельным
   субагентом (.qwen/agents/topic-verifier.md) с самодостаточным промптом
   (пути, не содержимое стандартов). Вердикт блокирующий; константы из реестра
   docs/topic-passports/reports/verified-constants.md не перепроверяются.
4. Шаги 2–6 — разработка: 3D-модели, практикум, 2D-рендеры, модульные
   компоненты, регистрация. Перед сдачей постпроверке выполни САМОПРОВЕРКУ
   разработчика (00-PIPELINE, шаг 5): аудит формул, grep-паттерны, blockId,
   DEFAULT_HOME_MOLECULES, ES-импорты, мёртвые экспорты.
5. Шаг 7 — запусти АГЕНТА ПОСТПРОВЕРКИ самостоятельным субагентом
   (.qwen/agents/topic-proofreader.md). Итерации до 0 critical.
6. Шаги 8–9 — финальная сборка и коммит (в сообщении — пути к отчётам).

Токен-дисциплина (обязательно): ролевые задачи — только самостоятельными
субагентами с чистым контекстом, без форков; стандарты в промпты не дублировать;
отчёты агенты пишут на диск сами, координатору возвращают только вердикт
(≤ 20–30 строк); большие файлы регистрации читать фрагментом через grep.
```

## Обязательное наполнение темы (контрольный список)

Координатор проверяет по паспорту и реестру эталонов; нормы — в модулях стандарта:

- **Теория в разделах**: 8–9 секций, каждая начинается вводным абзацем (30-DESIGN §3, §9).
- **Формулы и уравнения**: 100% через `ChemFormula`/`ChemText` (KaTeX, без mhchem); условия над стрелкой; кириллические условия — только проп `math`; константы — `math`; аудит `node scripts/audit-formulas.mjs` без ошибок (20-RENDERING §1).
- **Таблицы**: ≥ 2, «янтарная» сравнительная и таблица данных, числа `font-mono` (30-DESIGN §7).
- **Интересные факты**: ≥ 2, равномерно по секциям, только `TheoryCallout`, заголовок — название факта без префикса (30-DESIGN §5).
- **Тёмные блоки**: 2–5 (2–3 больших + 1–2 малых), разнообразное содержание, малые в гриде со светлой карточкой, `DarkBlockCard` (30-DESIGN §6).
- **2D-структурные формулы**: ≥ 4 схемы; тёмные плитки-превью с модалкой для одиночных формул; светлая панель при ≥ 3 формулах в разделе; `MolecularDiagram2D`/`MoleculeViewer2D`/`StructuralFormula2D`, академическая приглушённая палитра, угловые метки с названиями, 100% русский язык (20-RENDERING §2).
- **Простые схемы и tree-диаграммы с фигурными стрелками**: плотная сводная информация — tree-диаграмма без номера схемы, ветви с условиями/классами (20-RENDERING §2.6).
- **Инфографика**: концептуальные схемы — `InfographicFigure` (светлая тема, справочная панель справа, без модалок); интерактивные концепт-карты — `ConceptFlow` (React Flow); только там, где необходима (20-RENDERING §2.7–2.8).
- **3D-модели**: 8–9 молекул в `src/data/molecules.ts`, финальный раздел `section-molecules-3d`, НЕ в `DEFAULT_HOME_MOLECULES` (20-RENDERING §3).
- **Единообразие стиля**: шрифты `font-body`/`font-heading`/`font-mono` (`font-serif` запрещён), палитра slate/amber/rose/emerald/teal/sky/indigo/purple, шапка из 4 блоков, quick-nav ровно 3 тега, канонический набор иконок lucide-react, строчные названия элементов (30-DESIGN §1–2, §4, §8; 20-RENDERING §1.7).
- **Верификация и постпроверка**: отчёты обоих агентов на диске в `docs/topic-passports/reports/`, 0 critical, новые константы внесены в `verified-constants.md`.

## Критерий готовности

Отчёты верификации и постпроверки — 0 critical; аудит формул и `npm run build && npm run lint` чистые; паспорт актуализирован; коммит содержит пути к отчётам.
