# Профиль семейства «Общая химия» (ОХ-NN)

Профиль применяется к темам фундаментальной (общей) химии. Общие нормы — в модулях [`../10-ARCHITECTURE.md`](../10-ARCHITECTURE.md), [`../20-RENDERING.md`](../20-RENDERING.md), [`../30-DESIGN.md`](../30-DESIGN.md); данный файл фиксирует только семейные особенности.

## Идентификация

- Блок в [`studyBlocksData.ts`](../../../src/data/studyBlocksData.ts): **`general-chemistry`** («Общая химия»).
- Формат id: **`gen-*`**. Примеры: `gen-basics-laws`, `gen-ovr-basics`, `gen-solutions-rio`.
- Код темы: **`ОХ-NN`** (кириллица «ОХ» + порядковый номер).
- Поле `subgroup` отсутствует.

## Каркас и полное наполнение тем

Каркасы всех тем семейства (ОХ-01…ОХ-08) уже созданы: состав из трёх файлов (`<Topic>TheoryView.tsx` / `<Topic>Header.tsx` / `<Topic>Sections.tsx`) плюс ре-экспорт `src/components/study/topics/<Topic>TheoryView.tsx` ([`../10-ARCHITECTURE.md`](../10-ARCHITECTURE.md) §1); конспект — в `theoryLesson` записи `studyBlocksData.ts`.

**Каркас ценен только как разметка разделов**: массив `navItems` (id `section-*` и названия), якорная структура `Sections`, шапка из 4 блоков ([`../30-DESIGN.md`](../30-DESIGN.md) §4; мета-строка: код `ОХ-NN` • «Общая химия» • «Раздел N • <название раздела>»), регистрация в системе. Текстовое содержимое каркаса (`theoryLesson`, заглушки разделов) нормой не является и при наполнении заменяется.

**Полное наполнение темы** (каркас → полная тема) ведётся по общему стандарту:

1. Разметка разделов наследуется: id секций сохраняются (зафиксированы в паспорте темы), а их содержимое разрабатывается полностью и дополняется — вводные абзацы теории, таблицы, формулы, 2D-схемы, dark-блоки, интересные факты. Если контент требует, секции допускается добавлять, объединять или переименовывать — отклонение фиксируется в паспорте темы ([`../../topic-passports/`](../topic-passports/)).
2. Состав файлов расширяется до полного по образцу семейства ХЭ ([`../10-ARCHITECTURE.md`](../10-ARCHITECTURE.md) §1): `<Topic>DarkBlocks.tsx`, `<Topic>FunFacts.tsx`, `<Topic>2DRenders.tsx`, опционально `<Topic>Infographics.tsx` / `<Topic>ConceptFlow.tsx` — по необходимости контента.
3. 3D-раздел `section-molecules-3d` добавляется, если в теме есть визуализируемые молекулы ([`../20-RENDERING.md`](../20-RENDERING.md) §3).
4. Объём теории — не скуднее ориентиров ([`../30-DESIGN.md`](../30-DESIGN.md) §9; применяются к наполненной теме по аналогии с ХЭ).
5. `theoryLesson` остаётся кратким конспектом записи блока; полная теория живёт в разделах.

> **Правило развития семейства**: если при наполнении ОХ-темы появляется новый UI-элемент, ранее не встречавшийся в темах, он вводится через централизованные компоненты и фиксируется в настоящем профиле + в паспорте темы. Запрещено дублировать элементы локально ([`../10-ARCHITECTURE.md`](../10-ARCHITECTURE.md) §3, правило упреждающей централизации).

> Концептуальная инфографика ОХ-тем (классификации, количественные законы, формульные «хабы») — централизованный `InfographicFigure`; интерактивные концепт-карты — `ConceptFlow` (React Flow); применять только там, где необходима. Эталон — ОХ-01 ([`../20-RENDERING.md`](../20-RENDERING.md) §2.7–2.8). Спек `plots` поддерживает кривые `hyperbola`, `linear` и `energy` (энергетический профиль реакции: уровни реагентов/продуктов, барьер активации Ea, стрелка ΔH; проп `profile: 'exo' | 'endo'`) — введено в ОХ-05 (2026-08). Разреженные концепт-карты `ConceptFlow` получают пропы `layoutRx`/`layoutRy` (радиусы эллипса раскладки) и увеличенные `height`/`canvasMaxWidth`; размеры узлов измеряются по тексту, поэтому `fitView` не обрезает длинные подписи (введено в ОХ-05, 2026-08).

## Регистрация и практика

- Переход в практику: `openStudyBlock('general-chemistry', '<topic-id>', 'practice')` — блок обязан существовать ([`../10-ARCHITECTURE.md`](../10-ARCHITECTURE.md) §2, CAUTION про blockId).
- Текущие `trainerIds`: общий тестовый тренажёр `np-test-14-1`; `practiceTypes`: `['tests']`. Новые тематические тренажёры регистрируются в [`trainersRegistry.ts`](../../../src/data/trainersRegistry.ts).
- Маппинг в [`elementStudyService.ts`](../../../src/services/periodicTable/elementStudyService.ts) для ОХ-тем **не выполняется** (темы не привязаны к химическим элементам).
