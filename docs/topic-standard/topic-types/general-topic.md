# Профиль семейства «Общая химия» (ОХ-NN)

Профиль применяется к темам фундаментальной (общей) химии. Общие нормы — в модулях [`../10-ARCHITECTURE.md`](../10-ARCHITECTURE.md), [`../20-RENDERING.md`](../20-RENDERING.md), [`../30-DESIGN.md`](../30-DESIGN.md); данный файл фиксирует только семейные особенности.

## Идентификация

- Блок в [`studyBlocksData.ts`](../../../src/data/studyBlocksData.ts): **`general-chemistry`** («Общая химия»).
- Формат id: **`gen-*`**. Примеры: `gen-basics-laws`, `gen-ovr-basics`, `gen-solutions-rio`.
- Код темы: **`ОХ-NN`** (кириллица «ОХ» + порядковый номер).
- Поле `subgroup` отсутствует.

## Состав: каркас из трёх файлов

Темы семейства на текущем этапе создаются в **облегчённом каркасе** (теоретическое наполнение живёт в `theoryLesson` записи `studyBlocksData.ts`, UI-компоненты — каркас из трёх файлов в `src/components/study/topics/<topicSlug>/`):

| Файл | Зона ответственности |
|---|---|
| `<Topic>TheoryView.tsx` | Корневой компонент: `navItems`, `activeSection`, `scrollToNav()`, переход в практику |
| `<Topic>Header.tsx` | Шапка из тех же 4 блоков ([`../30-DESIGN.md`](../30-DESIGN.md) §4); мета-строка: код `ОХ-NN` • «Общая химия» • «Раздел N • <название раздела>» |
| `<Topic>Sections.tsx` | Разделы теории `#section-*`, таблицы, практикум-баннер |

Плюс ре-экспорт `src/components/study/topics/<Topic>TheoryView.tsx` ([`../10-ARCHITECTURE.md`](../10-ARCHITECTURE.md) §1).

**Отличия от семейства ХЭ на текущем этапе**:
- файлы `<Topic>DarkBlocks.tsx`, `<Topic>FunFacts.tsx`, `<Topic>2DRenders.tsx` в каркасах не создаются;
- 3D-раздел `section-molecules-3d` в каркасах отсутствует;
- объёмные ориентиры [`../30-DESIGN.md`](../30-DESIGN.md) §9 применяются по аналогии при наполнении темы, а не к каркасу.

> **Правило развития семейства**: если при наполнении ОХ-темы появляется новый UI-элемент (3D-раздел, тёмный блок, выноска, 2D-схема), он вводится через централизованные компоненты и фиксируется в настоящем профиле + в паспорте темы ([`../../topic-passports/`](../../topic-passports/)). Запрещено дублировать элементы локально ([`../10-ARCHITECTURE.md`](../10-ARCHITECTURE.md) §3, правило упреждающей централизации).

> Концептуальная инфографика ОХ-тем (классификации, количественные законы, формульные «хабы») — централизованный `InfographicFigure`; интерактивные концепт-карты — `ConceptFlow` (React Flow); применять только там, где необходима. Эталон — ОХ-01 ([`../20-RENDERING.md`](../20-RENDERING.md) §2.7–2.8).

## Регистрация и практика

- Переход в практику: `openStudyBlock('general-chemistry', '<topic-id>', 'practice')` — блок обязан существовать ([`../10-ARCHITECTURE.md`](../10-ARCHITECTURE.md) §2, CAUTION про blockId).
- Текущие `trainerIds`: общий тестовый тренажёр `np-test-14-1`; `practiceTypes`: `['tests']`. Новые тематические тренажёры регистрируются в [`trainersRegistry.ts`](../../../src/data/trainersRegistry.ts).
- Маппинг в [`elementStudyService.ts`](../../../src/services/periodicTable/elementStudyService.ts) для ОХ-тем **не выполняется** (темы не привязаны к химическим элементам).
