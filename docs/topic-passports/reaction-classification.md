## Уроки для будущих тем

- Классификация химических реакций требует точного сопоставления сразу по нескольким независимым критериям (например, синтез аммиака — гомогенный, экзотермический, обратимый, каталитический, ОВР, соединение).
- Энергетические диаграммы для экзо- и эндотермических реакций наглядно демонстрируют понятие энергии активации (E_a).
- Плитки `MoleculeViewer2D` со структурными формулами «участников реакций» в классификационной теме — лишний и ненаучный блок: концептуальное содержание передаётся только InfographicFigure/ConceptFlow.
- Кириллические условия над стрелкой (электролиз и т.п.) через проп `formula` не поддерживаются парсером и ловятся аудитом как policy-ошибка — только проп `math` с `\xrightarrow{\text{...}}` либо примеры с поддерживаемыми условиями (`-t->`, `-(MnO2)->`).
- В ConceptFlow с плотной семантикой (хаб + поддерево факторов) автораскладка «эллипс» даёт налезания — факторы размещаются явными координатами, а рёбра не должны пересекать хаб.
