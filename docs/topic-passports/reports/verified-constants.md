# Реестр верифицированных констант (S_Chem_Portal)

Накопительный реестр количественных констант, уже сверенных агентом научной верификации (`topic-verifier.md`) по двум источникам (RU + INT). Назначение — исключить повторные выборки одних и тех же величин в новых темах.

## Правила

1. **Использование**: константа из реестра применяется в темах и `specItems` без повторного fetch; в верификационном отчёте указывается статус ✅ и пометка «реестр: verified-constants.md».
2. **Пополнение**: каждую новую сверенную константу верификатор добавляет в реестр в тот же прогон (формат таблицы ниже). Запись без двух источников не вносится.
3. **Конфликты**: при расхождении реестра и новой сверки приоритет — CRC Handbook → NIST → PubChem → учебники; строка реестра обновляется, старое значение не сохраняется.
4. **Точность**: значение приводится в точности источника (округление — как в источнике); единицы обязательны.
5. Легенда источников: **ХЭ** — Химическая энциклопедия (xumuk.ru); **РШ** — российские школьные учебники/справочники (Третьяков, Лидин и др.); **ФИПИ** — кодификатор/демо ЕГЭ; **CRC** — CRC Handbook of Chemistry and Physics; **RSC** — периодическая таблица RSC (periodic-table.rsc.org); **NIST** — NIST Chemistry WebBook; **PubChem** — pubchem.ncbi.nlm.nih.gov.
