# Верификационный отчёт — ОХ-01 «Основные понятия и законы химии»

- **Объекты**: черновик теории `docs/topic-passports/reports/general-basics-draft.md` (утверждения [F1]–[F88], 14 задач практикума); паспорт `docs/topic-passports/general-basics.md` (согласованность).
- **Дата**: 2026-08-06. Агент: `topic-verifier` (S_Chem_Portal).
- **Метод**: каждое утверждение сверено минимум по двум независимым источникам (≥1 RU + ≥1 INT). Живые проверки выполнены по: NIST CODATA (u, NA, R, n₀), NIST Chemistry WebBook (ΔfH° H(g), N(g); Tкип H₂O), NIST CCCBDB (длины связей H₂, N₂), PubChem (CID 24602 — D₂O; CID 947 — N₂), CIAAW/IUPAC (хлор), IUPAC Gold Book (M03980 «mole», A00297 «amount of substance»), nobelprize.org (Перрен). Википедия (EN) использовалась только как первичная наводка для исторических дат; факты подтверждались первоисточниками и справочниками.
- **Статусы**: ✅ подтверждено; ⚠️ требуется уточнение формулировки (не блокирующее); ❌ ошибочно/не подтверждено (блокирующее).

**Условные обозначения источников**: Габриелян — учебник химии для 8/11 кл.; Некрасов — «Основы общей химии»; Глинка — «Общая химия»; Коровин — «Общая химия» (вуз); Пилипенко — Пилипенко, Сухан «Справочник по химии»; Потапов/Хомченко — «Химия»; Третьяков — «Неорганическая химия» (МГУ); ХимЭнцикл. — «Химическая энциклопедия» (М.: СЭ/БРЭ); Ломоносов ПСС — Полное собрание сочинений М. Фактически 0.78·28 + 0.21·32 = **28.56**; значение ≈ 28.9–29 достигается только с учётом аргона (~0.93 %, M = 40): 28.56 + 0.009·40 ≈ 28.93, а точное справочное значение M(воздуха) ≈ 28.96 г/моль (CRC). **Требуемое исправление**: заменить вывод на «M ≈ 0.78·28 + 0.21·32 + 0.009·40 ≈ 28.9 ≈ 29 г/моль» (или указать 28.96 г/моль).
