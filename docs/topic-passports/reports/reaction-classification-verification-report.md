**M-1 (minor)** — устаревшее термохимическое значение «92.4 кДж» в двух местах:
1. `src/components/study/topics/reactionClassification/ReactionClassificationDarkBlocks.tsx`, строка 132. Цитата: `N_2 + 3H_2 \xrightleftharpoons{Fe, t^\circ, p} 2NH_3 + 92.4 \text{ кДж}`.
2. `src/components/study/topics/reactionClassification/ReactionClassificationConceptFlow.tsx`, строка 37. Цитата: `'N₂ + 3H₂ ⇄ 2NH₃ + 92.4 кДж; 400–500 °C, 25–35 МПа, катализатор Fe'`.
Основание: NIST WebBook ΔfH°(NH₃, г) = −45.94 кДж/моль (→ 91.9 кДж на 2 моль NH₃); Wikipedia EN «Haber process»: ΔH = −92.28 кДж. Значение 92.4 кДж — устаревшее школьное округление (ΔfH = −46.2) вне современного диапазона 91.9–92.3.
Замена: `+ 92.2 кДж` в обоих местах (остальной текст строки 37 ConceptFlow — условия 400–500 °C, 25–35 МПа, Fe — подтверждён и сохраняется).

**M-2 (minor)** — `src/data/reactionClassificationTestTasks.ts`, строка 36.
Цитата: «Горение метана — обмен/окисление, …».
Основание: горение CH₄ + 2O₂ → CO₂ + 2H₂O не является реакцией обмена (обмен — два сложных вещества обмениваются составными частями без изменения СО); это реакция окисления/горения (ОВР). По числу и составу — не относится ни к одному из 4 классических типов.
Замена: «Горение метана — реакция окисления (горение), не являющаяся реакцией соединения; разложение нитрата — разложение, Zn + HCl — замещение.»

**M-3 (minor)** — `src/data/studyBlocksData.ts`, строка 302.
Цитата: `'2H2O -t-> 2H2^ + O2^'`.
Основание: в школьном курсе разложение воды проводится электролизом; термическая диссоциация воды существенна только при t > 2000 °C, условие «-t-» без оговорки вводит в заблуждение.
Замена: `'2H2O ->(эл. ток) 2H2^ + O2^'` (либо `'2H2O -(t>2000°C)-> 2H2^ + O2^'`).
