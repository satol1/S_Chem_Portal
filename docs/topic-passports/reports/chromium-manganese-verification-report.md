## Исправления для разработчика

### Блокирующие (❌)

1. **Раздел 1, «У обоих пять неспаренных электронов»** — неверно для хрома.
   Правильно: у Cr ([Ar]3d⁵4s¹) — **6 неспаренных электронов**, у Mn ([Ar]3d⁵4s²) — **5**. Обоснование высших степеней окисления строить через число валентных электронов: у Cr их 6 (поэтому высшая с.о. +6), у Mn — 7 (высшая +7).

2. **Раздел 2 и «Подводный камень ФИПИ» №1 — пассивация марганца.**
   Утверждение «конц. H₂SO₄ и конц. HNO₃ при 20 °C пассивируют оба металла» для **марганца не подтверждено и противоречит источникам**: Mellor (через PubChem HSDB) фиксирует, что концентрированная азотная кислота реагирует с марганцем «с раскалением и слабым взрывом»; в списках пассивирующихся металлов Mn отсутствует; русские источники (Некрасов, chem21) пассивацию Mn не упоминают.
   Исправление: пассивацию при 20 °C оставить **только для Cr**; для Mn написать, что концентрированные кислоты реагируют с ним (при нагревании — SO₂ и NO₂; водород не выделяется, т.к. кислоты — окислители). Фразу про «водород не выделяется никогда» сохранить — она верна для обоих металлов.

### Требующие правки/уточнения (⚠️)

3. **ρ(Mn) = 7.21 г/см³** — значение не подтверждено ни одним найденным источником. Найденные значения: CRC Handbook 86th ed. — **7.3 г/см³**; RSC — 7.3; Merck/ICSC — 7.47 г/см³ (α-Mn, 20 °C); chem21 (стар. данные) — 7.43.
   Рекомендация: заменить на **7.3 г/см³** (CRC/RSC) либо дать 7.44 г/см³ для α-модификации.

4. **E°(MnO₄⁻/MnO₂) = +0.59 В** — значение относится **только к щелочной** полуреакции MnO₄⁻ + 2H₂O + 3e⁻ → MnO₂ + 4OH⁻ (CRC 87th ed.: +0.595 В). В таблице Раздела 1 добавить пометку «(в щелочной среде)»; для кислой среды пара MnO₄⁻/MnO₂ имеет E° = +1.69 В (чтобы не вводить в заблуждение рядом с «кислыми» потенциалами).

5. **E°(MnO₄⁻/MnO₄²⁻) = +0.56 В** — оставить: значение стандартное (CRC, Vanýsek), но при данной верификации доступный онлайн-источник с числом не найден (в большой таблице потенциалов строка отсутствует). Разработчику иметь в виду.

6. **Получение Mn₂O₇**: вместо `2KMnO₄ + H₂SO₄(конц) → Mn₂O₇ + K₂SO₄ + H₂O` использовать препаративно точное
   `2KMnO₄ + 2H₂SO₄(конц) =(0 °C)> Mn₂O₇ + 2KHSO₄ + H₂O`
   (Lux // Brauer, Handbook of Preparative Inorganic Chemistry, vol. 2; Некрасов: холодная 90 %-ная H₂SO₄). Черновой вариант с K₂SO₄ сбалансирован, но в концентрированной кислоте образуется гидросульфат.

7. **Mn + вода**: формулировку «порошок медленно реагирует уже при 20 °C» смягчить — источники расходятся (chem21: «очень медленно реагирует с холодной водой» и одновременно «чистый Mn не разлагает воду при обычной температуре»; Некрасов: «при нагревании»). Рекомендация: «медленно реагирует с холодной водой, значительно быстрее — при нагревании».

8. **Ферромарганец «65–95 % Mn»**: Некрасов даёт 60–90 %. Рекомендация: оставить 65–95 % (совместимо с современными марками) или унифицировать в «60–95 %»; в любом случае не противоречит источникам грубо.

9. **MnO₃ в ряду кислотности оксидов** («MnO₃/Mn₂O₇ (кислотные)»): MnO₃ в свободном виде не получен. Убрать MnO₃ или добавить пометку «не получен в свободном виде» (стандартная формулировка ЕГЭ-материалов).

10. **Структурные параметры CrO₂Cl₂** (d(Cr=O) ≈ 1.57 Å, d(Cr–Cl) ≈ 2.12 Å, углы ~109–112°): не подтверждены доступными онлайн-источниками (PubChem без 3D/кристаллоструктур, COD без записи). Тетраэдрическая геометрия подтверждена (PubChem, дескриптор T-4). Оставить значения как учебные **с пометкой ⚠️** в specItems.

### Необязательные комментарии (можно отразить в теме примечаниями)

- ρ(Cr): оставить 7.19 (CRC: 7.192 при 20 °C); существуют варианты 7.14 (Merck) и 7.15 (ICSC).
- tкип(Cr): оставить 2671 °C (CRC/RSC); Merck даёт 2642 °C.
- tпл/tкип(Mn): оставить 1246/2061 °C (CRC); варианты ICSC 1244/1962 °C — устаревшие/округлённые.
- Цвет Cr(OH)₃: черновик «серо-зелёный» допустим; у Некрасова — «серо-синий» (в литературе встречаются оба варианта).
- Cr(OH)₃ + NaOH (раствор): форма Na₃[Cr(OH)₆] допустима; в ЕГЭ-материалах чаще Na[Cr(OH)₄] — можно показать оба варианта.
- Угол Cr–O–Cr в Cr₂O₇²⁻: 126° (α-K₂Cr₂O₇) / 123° (β-фаза, COD 2010992) — допустим диапазон 123–126°.
- d(Cr–O) в CrO₄²⁻: по COD 1520962 вычисляется 1.63–1.64 Å; учебное 1.65 Å допустимо.
- Нержавеющая сталь: формальный минимум 10.5–11 % Cr; диапазон черновика 12–20 % корректен как «типичный».
- Твёрдость Cr 8.5 (Моос) — для чистого металла; литой хром с примесями заметно мягче (по минералогической шкале ~4.5 — chem21).
