## Уроки для будущих тем

- Перечисления степеней окисления (`S(+6), N(+5), …`) парсер ChemFormula обрабатывает нестабильно (часть в скобках уходит в нижний индекс) — такие перечисления писать через проп `math` (`\mathrm{S^{+6},\ N^{+5},\ldots}`).
- Кириллица внутри `\xrightarrow{...}` и `\mathrm{...}` без `\text{}` — либо policy-ошибка аудита (условия над стрелкой), либо katex-error (`\mathrm{кириллица}`); все кириллические фрагменты — только в `\text{}`.
- Константы и символы величин (E° и т. п.) в прозе и заголовках таблиц оборачивать в `ChemFormula math=...` — постпроверка ловит их вне KaTeX.
- Тестовый тренажёр ОХ-темы удобно строить по образцу `rc-test-01`: данные `<Topic>TestTasks.ts` + тонкий компонент на `GenericTrainerContainer`/`MultipleChoiceMatchingAdapter`; эталоны ответов верифицируются в одном прогоне с черновиком теории ([F60]–[F71]).
- Тёмным 2D-плиткам ионов подходят токены смежных элементов палитры с комментарием: Mn — фиолетовый токен (окраска перманганата), Cr — оранжевый (окраска дихромата), собственных токенов Mn/Cr в `molecule2DTheme` нет.
- Символы элементов в SVG-подписях инфографик — только по-русски («Анионы кислотных остатков», не «Acid⁻»): постпроверка трактует английский в графике как critical.
