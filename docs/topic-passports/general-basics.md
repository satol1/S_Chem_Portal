## Вещества, 2D и 3D

- Вещества темы: вода, оксиды углерода (CO, CO₂), ряд оксидов азота (N₂O, NO, N₂O₃, NO₂, N₂O₅) для закона кратных отношений, простые газы (H₂, O₂, N₂, Cl₂), NH₃, CH₄, HCl, тяжёлая вода D₂O, дейтерий/тритий как примеры изотопов.
- 2D-схемы (`GeneralBasics2DRenders.tsx`, типы рендера): `mixtures-classification` (вещества и смеси + способы разделения), `multiple-proportions` (оксиды азота, отношение кислорода 1:2:3:4:5), `mole-hub` (формульный узел расчётов количества вещества), `gas-laws` (изопроцессы идеального газа).
- Tree-диаграмма (JSX-паттерн 20-RENDERING §2.6): классификация веществ (простые/сложные → классы неорганических соединений) в секции `section-simple-complex`.
- 3D-модели (id в `molecules.ts`): `h2, n2, o2, h2o, co2, ch4, nh3, hcl, cl2` — 9 моделей; `h2` и `n2` добавляются при наполнении темы (не добавлять в `DEFAULT_HOME_MOLECULES`).

## Уроки для будущих тем

- Первая полная тема семейства ОХ: каркас из 3 файлов эволюционирует до полной темы добавлением `DarkBlocks`/`FunFacts`/`2DRenders` + 3D-раздела («правило развития семейства» из `topic-types/general-topic.md`); id секций каркаса сохраняются, лейблы перенумеровываются при вставке новых разделов.
- Верификация поймала арифметическую ошибку в выводе (средняя M воздуха: 0.78·28 + 0.21·32 = 28.56, а не 28.8) — любую арифметику в черновике пересчитывать отдельно, даже если вывод выглядит правдоподобно.
- API `TermTooltip` — отображаемое слово передаётся пропом `term` (не children); перед копированием паттернов проверять интерфейс компонента.
- Концептуальные (немолекулярные) 2D-схемы — ветвления, бары, «хабы» формул — собираются на `SvgDiagramWrapper` + токенах `getThemePalette` без молекулярных примитивов; автоподбор viewBox компактного режима работает и для них.
- Исторические сюжеты (Ломоносов/Лавуазье, Карлсруэ-1860, измерение Nₐ) хорошо ложатся в dark-блоки формата «стадии»; содержание dark-блоков не обязано быть промышленным.
